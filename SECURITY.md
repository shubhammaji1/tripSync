# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of TripSync very seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please send an email to **security@tripsync.io** with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigations (if available)

We will acknowledge receipt of your report within 48 hours and work with you on a timely resolution.
